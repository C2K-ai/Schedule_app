# 시간표 칸 디자인 가이드 (2026-10-12)

사용자가 보낸 5가지 지적을 실제 코드와 대조해 정한 값. 화면 코드는 `src/components/TimetableView.tsx` 의 `Grid`.

| # | 지적 | 확인 결과 | 정한 것 |
|---|---|---|---|
| 1 | 모서리 곡률이 칸마다 다름 | 코드상 모두 `rounded-lg`(8px)로 같았음. 금요일 칸이 진한 원색이라 둥글어 보인 착시 | 모든 칸 **10px**(`rounded-[10px]`) 하나로 고정. 테두리 1px + 왼쪽 3px 색 띠로 모양을 또렷하게 |
| 2 | 현재 시각 선이 14:00 에 멈춤 | 선 위치는 맞았음(1분마다 갱신). 시각 숫자가 선 **아래** 칸 안에 붙어 있어 '14' 숫자 줄을 14:00 선으로 읽게 됨 | 시각 숫자를 **선 높이에 세로 가운데**로(`-translate-y-1/2`), 지금 선 왼쪽 끝에 점 + 시각 칸에 **'14:29' 빨간 배지**. 위아래 끝 숫자가 안 잘리게 그리드 위아래 8px 여백 |
| 3 | 칸 안 여백 부족 | 맞음 — `px-1 py-0.5`(4px/2px) | 폰 `px-1.5 py-1`(6px/4px), PC `md:px-2.5 md:py-2`(10px/8px). 칸 사이 2px 틈(위아래 1.5px·좌우 2px). 글자 폰 11px/10px, PC 13px/12px. 줄바꿈은 낱말 단위(`word-break: keep-all` + `overflow-wrap: anywhere`) — "기업법과 범/죄"처럼 글자 중간에서 끊기지 않게 |
| 4 | 어두운 배경에서 원색이 튐(형광 연두) | 맞음 — 칸 바탕이 팔레트 원색 그대로(#C8FF2E 등)였음 | 바탕 = `color-mix(in oklab, 색 30%, var(--bg))` — 어두운 테마에선 짙은 색조, 밝은 테마에선 파스텔이 저절로 됨. 글자는 테마 글자색(`text-fg`, 강의실은 `text-muted`)이라 대비가 늘 충분. 색은 왼쪽 3px 띠(`inset 3px 0 0 색`)와 1px 테두리(색 45%)로 알아봄 |
| 5 | 수업 없는 요일이 휑함 | 맞음 — 모든 요일이 같은 폭 | 수업 없는 평일은 **0.45 폭**으로 좁히고 가운데에 세로 글씨 **'공강'**(text-faint). 월~금은 늘 보이게(요일 위치가 바뀌지 않게), 토·일은 수업 있을 때만 |

그 밖에: 한 시간 높이 폰 54px / PC 60px, 시각 칸 너비 2.5rem, 오늘 요일 칸은 `bg-accent/5` 로 살짝.
