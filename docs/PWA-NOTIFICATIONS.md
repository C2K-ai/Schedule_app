# 폰·노트북에 설치하고 알림을 놓치지 않게 — 단계별

## 먼저 알아 둘 것 (1분)

| 상황 | 무엇이 울리나 |
|---|---|
| 앱이 **열려 있음** (다른 탭에 가려져 있어도) | 앱이 직접 울림 — **전체화면 알람 + 내가 고른 알람음 + 음성 + 진동** |
| 앱이 **닫혀 있음** | 서버 푸시 → OS 시스템 알림 (소리는 OS 알림음). Supabase 연결 필요 — [SETUP-SUPABASE.md](SETUP-SUPABASE.md) |
| 노트북 **덮개 닫음 / 절전** | 아무것도 못 받습니다. 폰이 받습니다 → **폰에도 꼭 설치** |

- 설치·푸시는 **HTTPS 주소**에서만 됩니다(개발 중 `localhost` 는 예외). 배포는 SETUP 문서의 “선택 A”.
- 알림 권한은 **버튼을 눌러서** 요청해야 합니다(특히 iPhone). 앱의 **설정 → 알림 → 알림 켜기**를 쓰세요.
- 같은 알림이 앱·서버에서 동시에 와도 한 번만 표시됩니다.

---

## 노트북 — Windows (Chrome · Edge)

1. 앱 주소 접속 → 주소창 오른쪽 **설치 아이콘**(⊕ / 모니터 모양) 또는 상단 **‘앱 설치’** 버튼 → 설치
   - 시작 메뉴·작업 표시줄에 MUST 가 생기고, 창 없이 독립 앱으로 열립니다
2. 설치된 MUST 실행 → **설정 → 알림 → 알림 켜기** → 허용
3. (서버 연결 시) 같은 화면에서 **이 기기 등록** → **서버 푸시 테스트**
4. Windows **설정 → 시스템 → 알림**
   - 맨 위 **알림** 켜기
   - 앱 목록에서 **MUST**(또는 Chrome/Edge) 켜기 → 들어가서 **배너 표시**, **알림 센터에 표시**, **소리 재생** 켜기
5. 같은 화면의 **방해 금지 / 집중**: **우선 순위 알림 설정 → 앱 추가 → MUST**
   - 집중 시간에도 MUST 알림은 뚫고 옵니다
6. 브라우저를 닫아도 받으려면
   - Chrome: `chrome://settings/system` → **Google Chrome이 닫혀도 백그라운드 앱 계속 실행** 켜기
   - Edge: `edge://settings/system` → **Microsoft Edge가 닫혀 있을 때 백그라운드 확장 및 앱 계속 실행** 켜기
7. 확인: **설정 → 알림 → 시스템 알림 테스트**, **전체화면 알람 미리보기**

팁: 작업 표시줄에 MUST 를 고정해 두면 미시작 일정 수가 **앱 아이콘 배지**로 보입니다.

## 노트북 — macOS (Chrome · Edge · Safari 17+)

1. Chrome/Edge: 주소창 설치 아이콘 → 설치. Safari: **파일 → Dock에 추가**
2. MUST 실행 → **설정 → 알림 → 알림 켜기**
3. **시스템 설정 → 알림 → MUST**(또는 Chrome): 알림 허용, 스타일 **알림(Alerts)** — 배너는 몇 초 뒤 사라지지만 ‘알림’은 누를 때까지 남습니다
4. **시스템 설정 → 집중 모드** → 각 집중 모드 → 허용된 앱에 MUST 추가

## 핸드폰 — Android (Chrome)

1. Chrome 으로 앱 주소 접속 → 오른쪽 위 **⋮ → 앱 설치**(또는 홈 화면에 추가) → 설치
2. 홈 화면의 **MUST 아이콘으로 실행**(브라우저 탭 말고)
3. **설정 → 알림 → 알림 켜기** → 허용 → **이 기기 등록** → **서버 푸시 테스트**
4. 안드로이드 **설정 → 애플리케이션 → MUST → 알림**
   - 알림 허용, 카테고리를 **‘소리 및 팝업’ / 중요도 높음**으로
   - **잠금 화면에 표시** 켜기
5. **배터리를 ‘제한 없음’으로** — 이게 제일 중요합니다
   - 설정 → 애플리케이션 → MUST(그리고 **Chrome** 도) → 배터리 → **제한 없음**
   - 삼성: 설정 → 배터리 → 백그라운드 사용 한도 → **사용하지 않는 앱을 절전 상태로** 끄기, **절전 예외 앱**에 MUST·Chrome 추가
6. **방해 금지 예외**: 설정 → 알림 → 방해 금지 → 앱 → MUST 추가
7. **닫혀 있어도 내 알람음으로**: 앱 **설정 → 소리** 에서 원하는 소리 옆 **↓** 로 파일 저장 →
   안드로이드 설정 → 애플리케이션 → MUST → 알림 → 카테고리 → **소리** → 저장한 파일 선택

## 핸드폰 — iPhone / iPad (iOS 16.4 이상)

iPhone 은 **홈 화면에 설치한 앱만** 알림을 받을 수 있습니다. 순서가 중요합니다.

1. **Safari** 로 앱 주소 접속 (Chrome 앱 X)
2. 아래 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**
3. 홈 화면의 **MUST 아이콘으로 실행**
4. **설정 → 알림 → 알림 켜기** → 허용 (반드시 설치된 앱 안에서, 버튼으로)
5. 설정 → 동기화 → 이메일 코드로 로그인 → 설정 → 알림 → **이 기기 등록** → **서버 푸시 테스트**
6. iPhone **설정 → 알림 → MUST**: 알림 허용, 잠금 화면·알림 센터·배너, 배너 스타일 **지속적**
7. **설정 → 집중 모드** → 사용하는 모드 → **앱 → MUST 추가** (수면·업무 모드에서도 오게)

iPhone 의 한계(웹 앱 공통)
- 알림의 “지금 시작 / 5분 뒤 다시” 버튼이 보이지 않습니다 → 알림을 누르면 앱이 열리고 거기서 처리
- 닫혀 있을 때 오는 알림의 소리·진동 패턴은 바꿀 수 없습니다(시스템 기본음)
- 무음 스위치가 켜져 있으면 앱 알람음도 작아지거나 안 날 수 있습니다. 지원하는 iOS 버전에서는 무음 스위치와 상관없이 울리도록 요청해 두었지만(Audio Session API), 확실히 하려면 무음 스위치를 끄세요

## 놓치지 않기 체크리스트

- [ ] 폰에 **설치한 앱**으로 열어서 알림 권한 허용
- [ ] 폰 배터리 **제한 없음** (안드로이드)
- [ ] 폰·노트북 모두 **이 기기 등록** + **서버 푸시 테스트** 성공
- [ ] OS 방해 금지/집중 모드 **예외에 MUST**
- [ ] 노트북은 MUST 를 작업 표시줄/Dock 에 고정 (배지로 미시작 수 확인)
- [ ] 중요한 일정은 **알림을 2개 이상**(예: 10분 전 + 정각) + **강제 모드 켜기**
- [ ] 앱 설정 → 알림 → **점점 크게**, **제목 읽어 주기** 켜기

## 자주 묻는 것

**Q. 앱을 닫았는데도 내가 만든 알람 소리가 나게 할 수 없나요?**
웹 표준상 서비스 워커는 소리를 낼 수 없어서 OS 알림음이 납니다. 안드로이드는 위 7번처럼 파일을 알림 채널 소리로 지정하면 됩니다. Windows·iPhone 은 OS 알림음만 가능합니다. 대신 앱이 열려 있으면(최소화·다른 탭 포함) 항상 자체 알람음이 울립니다.

**Q. 정각에 정확히 오나요?**
앱이 열려 있으면 1초 단위로 확인해서 정각에 울립니다. 닫혀 있으면 서버가 1분마다 확인하므로 정각 + 수 초 안에 옵니다(설정으로 20초 단위까지 가능). 안드로이드는 배터리 ‘제한 없음’이 아니면 몇 분 늦을 수 있습니다.

**Q. 알림이 두 번 와요.**
같은 일정·같은 종류는 tag 가 같아서 교체됩니다. 두 번 온다면 서로 다른 종류(예: 10분 전 + 정각)이거나, 같은 기기를 두 계정으로 등록한 경우입니다 — 로그아웃하면 그 기기 등록이 자동으로 지워집니다.
